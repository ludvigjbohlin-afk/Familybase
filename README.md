# Hushållsbalans

Den smarta familjeassistenten som gör hela hushållsarbetet synligt och hjälper hushållet att dela det rättvist: sysslor, mental belastning, kalender, inköp, middagar, barn och rättvis fördelning, för alla sorters hushåll.

**Vårt löfte:** Ingen reklam. Ingen försäljning av personuppgifter. Inga offentliga profiler. Barnens data stannar inom hushållet.

Webbapp (PWA) som körs på GitHub Pages med Supabase som databas och inloggning. Dataskydd: se `docs/dataskydd.md`. Databasändringar som ska köras för hand ligger i `supabase/migrations/`.

- `index.html` – hela appen
- `manifest.webmanifest`, `sw.js`, ikoner – gör att appen kan installeras på hemskärmen
